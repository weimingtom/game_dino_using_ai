# Dino Run - SDL2 恐龙跳跃游戏

基于 SDL2（通过 pygame 绑定）实现的 Chrome 恐龙跑酷游戏。

## 运行

```bash
python dino_py/dino_game.py
```

## 操作

| 按键 | 功能 |
|---|---|
| 空格 / 上箭头 | 跳跃 |
| R / 空格 | 游戏结束后重新开始 |
| ESC | 退出 |

## 类结构

| 类 | 职责 |
|---|---|
| `Dinosaur` | 角色物理（重力、跳跃速度）、两帧跑步动画、矩形/圆形组合绘制 |
| `Obstacle` | 仙人掌障碍物，三种高度（36/48/40），带枝干 |
| `Ground` | 滚动地面线 + 石子装饰纹理 |
| `Cloud` | 背景云朵，视差滚动 |
| `Game` | 主循环、事件处理、障碍物生成、碰撞检测、分数管理、UI 渲染 |

## 核心数值

| 参数 | 值 |
|---|---|
| 画面尺寸 | 800×400 |
| 帧率 | 60 FPS |
| 重力加速度 | 0.7 px/frame |
| 跳跃初速度 | -14 px/frame |
| 初始移动速度 | 6 px/frame |
| 最高速度 | 14 px/frame |
| 速度增量 | 0.002 / 得分 |
